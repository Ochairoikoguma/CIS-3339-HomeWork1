# CIS 3339 Homework 1 — Student Management System (Vue 3 + MongoDB)

A full-stack Student Management System migrated from a plain HTML/JS frontend to
**Vue 3 (Composition API)**, with **Vue Router**, **Pinia**, an **Express** REST API,
and **MongoDB** for persistence.

## Features

- Add, search, display, and delete students
- Add, list, and delete courses
- Enroll students in courses and view a course roster
- Duplicate prevention for student IDs, course IDs, and enrollments
- Cascading deletes: removing a student or course also removes related enrollments
- Production build served directly by the Express backend

## Required Software

- [Node.js](https://nodejs.org/) (LTS version) and npm
- [MongoDB Community Edition](https://www.mongodb.com/try/download/community), running locally
- A modern web browser

## Required Environment Variables

Defined in `backend/.env` (already included in this repository):

```
MONGODB_URI=mongodb://127.0.0.1:27017/cis3339_homework1
PORT=3000
```

No changes are needed to run the app locally — this points to a local MongoDB instance
and does not require MongoDB Atlas, cloud credentials, or any external service.

## 1. Start MongoDB

macOS (Homebrew):
```bash
brew services start mongodb-community@7.0
```

Confirm it's running:
```bash
brew services list
```

MongoDB does not need to be pre-configured. The application automatically creates the
database, collections, schemas, and indexes on first use.

## 2. Install Dependencies

From the project root, this installs both the backend and frontend dependencies:
```bash
npm run install:all
```

## 3. Build the Frontend

Compiles the Vue application into static production assets (`frontend/dist/`):
```bash
npm run build
```

## 4. Start the Application

```bash
npm start
```

This starts the Express server, which serves the built Vue frontend and the REST API
from a single process.

## 5. Open the Application

```
http://localhost:3000
```

## Development Mode (optional)

For active development with hot-reload, run the backend and frontend dev server in two
separate terminals instead of the production build:

**Terminal 1 — backend:**
```bash
cd backend
node server.js
```

**Terminal 2 — frontend (Vite dev server):**
```bash
cd frontend
npm run dev
```

Then open `http://localhost:5173`. API requests are proxied to the backend on port 3000.


## Troubleshooting

**Backend can't connect to MongoDB**
Confirm MongoDB Community Edition is running (`brew services list`) and that
`backend/.env` contains a valid local `MONGODB_URI`.

**Blank page or 404 in production**
Run `npm run build` again and confirm `frontend/dist/index.html` exists, then restart
the server with `npm start`.

**Dependency errors**
Re-run `npm run install:all` from the project root.
